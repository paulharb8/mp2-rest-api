# MP2 REST API

This project is a FastAPI application that lets a client upload a CSV file, process it, and retrieve the results over HTTP. `POST /upload` accepts a CSV and stores it in memory, returning its dataset ID, filename, row and column counts, and column names. `GET /datasets/{dataset_id}` returns up to `limit` stored rows along with the total row count, and `GET /health` reports the application status and version. `POST /datasets/{dataset_id}/process` takes a JSON configuration, validates and cleans the stored dataset using the MP1 modules in `data_pipeline/`, replaces the stored data with the cleaned result, and returns a report of what was removed. Pydantic models in `src/models.py` define the request and response shapes, `src/storage.py` holds the in-memory datasets, and `src/middleware.py` logs every request with a request ID, status code, and duration, and returns the ID in an `X-Request-ID` header. Errors are returned as HTTP 400, 404, or 422 responses, and unexpected failures return a generic 500 while the traceback is logged. Pytest tests in `tests/` use FastAPI's `TestClient` to check the upload, process, and retrieve workflow.
